
# Kali Linux Cybersecurity Lab

## Overview

This repository documents my setup of a Kali Linux virtual machine as part of my cybersecurity internship at NetworkWalks.com.

The project focuses on establishing a virtual cybersecurity lab environment, documenting the setup process, and developing practical familiarity with Linux and cybersecurity lab workflows.

## Objectives

* Set up and run a Kali Linux virtual machine.
* Become familiar with the Kali Linux environment.
* Document the lab configuration and setup process.
* Build a foundation for future cybersecurity practical exercises.
* Maintain a structured record of my technical learning.

## Lab Environment

* **Operating System:** Kali Linux
* **Virtualization Platform:** VirtualBox 
* **Host Operating System:** Windows
* **Project Status:** VM setup completed and booting successfully

## Setup Process

1. Downloaded the appropriate Kali Linux image.
2. Configured the virtual machine using virtualBox.
3. Allocated the required virtual machine resources.
4. Installed or imported Kali Linux.
5. Started the virtual machine and verified that it booted successfully.
6. Documented the environment and setup progress.
